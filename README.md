# Token Status

**Windows · macOS** 트레이 앱. Claude Code · Codex CLI · Gemini CLI 의 사용량을 실시간 % 로 트레이/오버레이에 표시합니다.

작업 중 토큰을 얼마나 썼는지, 5시간 한도에 얼마나 가까운지 창을 띄우지 않고 한눈에 확인할 수 있습니다.

## 주요 기능

- **트레이 아이콘** — 사용률에 따라 색이 바뀌는 디스크 + % 숫자 (초록 <70% · 노랑 70–89% · 빨강 ≥90%)
- **상태창** — 세 프로바이더의 사용량을 한 화면에서 비교
- **오버레이 HUD** — 항상 위에 떠 있는 반투명 막대. 위치/크기 조절, 클릭 통과 잠금 지원
- **Claude OAuth 연동** — Claude Code 로그인으로 정확한 사용량을 자동 표시
- **자동 시작** — 로그인 시 트레이로 조용히 실행 (Windows · macOS)

## 측정 방식과 정확도

| 프로바이더 | 데이터 출처 | 정확도 |
|---|---|---|
| **Claude Code** | 실행 프로필의 OAuth · 호환용 웹 세션 · 로컬 로그 순서 | OAuth 사용 시 **공식 사용량** |
| **Codex** | `~/.codex/sessions/*.jsonl` 의 `used_percent` | **공식** — OpenAI가 직접 보고 |
| **Gemini** | `~/.gemini/tmp/**/{logs.json, session-*.json}` | 추정 — 메시지 수 기반 |

> Codex 는 별도 설정 없이 정확합니다. Claude 는 실행 프로필에 로그인하면 자동 연결됩니다.
> Gemini 는 CLI 가 토큰 카운트를 기록하지 않아 메시지 수로 근사하며, 현재로선 정확값을 얻을 방법이 없습니다.

## 빠른 시작 (처음이라면 이대로)

**전제 — Python 3.10 이상이 설치되어 있어야 합니다.**
없다면 먼저 설치하세요:
- Windows: [python.org/downloads](https://www.python.org/downloads/) 에서 설치. **설치 첫 화면의 "Add python.exe to PATH" 를 꼭 체크**하세요.
- macOS: 터미널에서 `brew install python` (Homebrew) 또는 python.org 설치 파일.

설치 여부 확인:
```bash
python --version      # Windows
python3 --version     # macOS
```

### Windows
1. 이 저장소를 내려받습니다 (초록색 **Code → Download ZIP** → 압축 해제, 또는 `git clone`).
2. 압축을 푼 폴더에서 **`install.bat` 더블클릭** → 의존성 설치가 끝날 때까지 기다립니다.
3. **`run.bat` 더블클릭** → 화면 우측 하단 트레이에 아이콘이 뜹니다.

### macOS
1. 저장소를 내려받습니다 (`git clone https://github.com/maroLee0409/Token_Status.git`).
2. 터미널에서 폴더로 이동 후:
   ```bash
   cd Token_Status
   chmod +x install.sh run.sh   # 최초 1회 실행 권한 부여
   ./install.sh                 # 설치
   ./run.sh                     # 실행
   ```
3. 화면 상단 메뉴바에 아이콘이 뜹니다.

> 끝입니다. 이제 트레이/메뉴바 아이콘에 사용량 %가 표시됩니다.

## 실행 방법 상세

### 설치 (`install.bat` / `install.sh` 가 하는 일)
- 프로젝트 폴더 안에 `.venv/` 가상환경을 만들고
- `requirements.txt` 의 의존성(PyQt6 · keyring · requests · Pillow)을 설치합니다.
- 한 번만 실행하면 됩니다. (의존성 업데이트가 필요할 때 다시 실행)

### 실행 (`run.bat` / `run.sh`)
```bash
# Windows
run.bat

# macOS · Linux
./run.sh
```

### 트레이 없이 백그라운드로만 시작
상태창을 띄우지 않고 트레이/메뉴바로만 조용히 시작합니다 (자동 시작과 동일한 동작):
```bash
run.bat --tray        # Windows
./run.sh --tray       # macOS
```

### 가상환경 없이 직접 실행 (개발자용)
```bash
pip install -r requirements.txt
python launcher.py
```

## 사용 설명서

### 1. 트레이 / 메뉴바 아이콘
- 아이콘의 **색 디스크 + 숫자**가 현재 사용률입니다. 초록(여유) → 노랑(주의) → 빨강(임박).
- 기본은 세 프로바이더 중 **가장 높은 값**을 표시합니다 (설정에서 평균으로 변경 가능).
- 마우스를 올리면 **툴팁**에 Claude/Codex/Gemini 각각의 % 가 나옵니다.

### 2. 마우스 동작
| 동작 | 결과 |
|---|---|
| **좌클릭** | 상태창 열기/닫기 |
| **우클릭** | 메뉴: 새로고침 · 오버레이 위치 초기화 · 오버레이 잠금 · 설정 · 종료 |

### 3. 표시 모드 (설정 → 일반 → 표시 모드)
- **표준** — 모든 정보 표시
- **간소** — % + 막대만
- **최소** — 한 줄 (이름 + %)
- **오버레이** — 항상 위에 떠 있는 반투명 HUD

### 4. 오버레이 사용법
설정에서 표시 모드를 **오버레이** 로 바꾸면 작은 반투명 막대가 화면 위에 항상 떠 있습니다.
- **이동** — 막대를 드래그
- **크기 조절** — 가장자리를 잡고 드래그
- **위치 잠금 = 클릭 통과** — 잠그면 마우스 클릭이 오버레이를 *그대로 통과*해서 뒤에 있는 창/버튼을 정상적으로 누를 수 있습니다. 화면을 가리지만 방해하지 않습니다.
  - 잠금/해제는 **트레이 우클릭 메뉴**, **설정 → 일반**, **오버레이 우클릭** 어디서든 가능
  - ⚠️ 잠근 상태에서는 오버레이를 우클릭할 수 없으니, 해제는 **트레이 메뉴**에서 하세요.
- **위치 자동 복구** — 모니터를 분리하거나 해상도가 바뀌어 오버레이가 화면 밖으로 사라지면 **자동으로 우상단으로 되돌아옵니다.** 안 되면 트레이 메뉴 → "오버레이 위치 초기화".

### 5. 새로고침
- 기본 30초마다 자동 갱신 (설정에서 5초~1시간 조절).
- 즉시 갱신하려면 트레이 우클릭 → "지금 새로고침".

## Claude 정확 사용량 연동

Claude 계정마다 **전용 실행 프로필**을 만들고 공식 `claude auth login`을 한 번
진행하면, 해당 프로필의 갱신 가능한 OAuth 인증으로 사용량을 자동 조회합니다.

1. 앱에서 **설정 → 추가 계정 → Claude 계정**을 선택합니다.
2. **전용 프로필**을 선택합니다. 새 계정은 처음부터 전용 프로필로 생성됩니다.
3. **로그인**을 눌러 해당 계정으로 공식 OAuth 승인을 완료합니다.
4. 이후 **이 계정으로 실행** 또는 트레이의 **Claude 계정으로 실행**을 사용합니다.

OAuth access token이 만료되면 앱이 같은 프로필의 refresh token으로 갱신하므로,
브라우저에서 개인/회사 계정을 전환해도 사용량 연결이 끊기지 않습니다. 여러
계정의 `.credentials.json`을 공용 `~/.claude`에 복사해 갈아 끼우지 않습니다.
OAuth 로그인 자체의 최종 유효기간은 Anthropic 정책을 따르므로 만료 시 해당
프로필만 다시 승인해야 하지만, 계정 전환 때문에 다른 계정 인증까지 깨지지는 않습니다.

기존 `sessionKey` 연동은 OAuth 사용량을 제공하지 않는 계정을 위한 호환용
폴백으로만 남아 있습니다. 웹 키가 403으로 만료되어도 OAuth 조회가 성공하면
사용량 표시는 영향을 받지 않습니다. OAuth도 사용할 수 없으면 로컬 로그 기반
추정값으로 자동 전환합니다.

**Codex 와 Gemini 는 세션 키가 필요 없습니다.** Codex 는 로컬 로그에 OpenAI 공식 % 가 들어 있어 자동으로 정확하고, Gemini 는 (CLI 한계로) 메시지 수 기반 추정만 가능합니다.

## 자동 시작

설정 → 일반 → **"시작 시 자동 실행"** 체크. 다음 로그인부터 트레이로 조용히 실행됩니다.

- Windows — 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\TokenStatus` 에 등록
- macOS — `~/Library/LaunchAgents/com.TokenStatus.plist` (launchd) 생성

체크를 해제하면 등록이 제거됩니다.

---

## 설정 파일 위치

- Windows — `%APPDATA%\TokenStatus\config.json`
- macOS — `~/Library/Application Support/TokenStatus/config.json`

로그 파일은 같은 폴더의 `log.txt` 입니다. 설정창 → "로그 보기" 로 바로 열 수 있습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 트레이 아이콘이 안 보임 | Windows: 트레이의 `^` (숨겨진 아이콘) 안에 있을 수 있음 → 끌어내어 고정. |
| 오버레이가 사라짐 | 트레이 우클릭 → "오버레이 위치 초기화" (모니터/해상도 변경 시 자동 복구도 됨). |
| Claude % 가 0 / 부정확 | 설정 → 계정 관리에서 해당 전용 프로필의 로그인 상태를 확인. |
| 계정 전환 후 다시 로그인하라고 함 | 공용 인증 교체 대신 트레이 → "Claude 계정으로 실행"에서 전용 프로필로 새 창 실행. |
| `install.bat` 이 python 못 찾음 | Python 재설치 시 "Add to PATH" 체크, 또는 터미널에서 `python --version` 확인. |
| 자세한 오류 확인 | 설정창 → "로그 보기" 로 `log.txt` 열기. |

## 알려진 한계

- **열린 창의 계정 즉시 교체 미지원** — 안전을 위해 계정마다 전용 프로필의 새 Claude 창을 실행합니다.
- **Gemini 토큰 미지원** — Gemini CLI 가 토큰 카운트를 기록하지 않아 메시지 수 기반 추정입니다.
- **Claude 로컬 폴백** — OAuth와 호환용 웹 세션을 모두 사용할 수 없으면 로컬 로그 추정값을 사용합니다.
